# Digital Advertising System

## Overview

A comprehensive digital advertising system built with Next.js and Supabase, designed for displaying advertisements on screens in public spaces. The system consists of two main components:

1. **Display System** - A public-facing interface that shows advertisements in fullscreen mode with automatic rotation.
2. **Admin Panel** - A management interface for adding, editing, and scheduling advertisements.

This application is perfect for digital signage in retail stores, waiting rooms, public areas, or any location where scheduled visual content needs to be displayed.

## Features

### Display System
- Fullscreen advertisement display
- Automatic rotation between multiple advertisements
- Support for both image and video advertisements
- Responsive design for different screen sizes
- Indicator dots showing current ad position in the rotation
- Error and loading states

### Admin Panel
- Complete CRUD operations for advertisements
- Media upload functionality supporting images and videos
- Advertisement scheduling with start and end times
- Preview functionality to see how ads will look on displays
- Active/inactive status toggling
- Responsive dashboard interface

## Technology Stack

- **Frontend Framework**: Next.js 14+ (App Router)
- **Database & Backend**: Supabase (PostgreSQL)
- **File Storage**: Supabase Storage
- **Styling**: Tailwind CSS
- **Language**: JavaScript
- **State Management**: React Hooks
- **Authentication**: Not implemented in the initial version (can be added with Supabase Auth)

## Setup Instructions

### Prerequisites
- Node.js (v18 or newer)
- npm or yarn
- Supabase account

### Installation

1. Clone the repository:
   ```bash
   git clone <repository-url>
   cd advertising-system
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Set up environment variables:
   - Copy `.env.local` to your project root directory
   - Update with your Supabase credentials:
     ```
     NEXT_PUBLIC_SUPABASE_URL=https://your-project-id.supabase.co
     NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key-from-supabase-project-settings
     ```

4. Run the development server:
   ```bash
   npm run dev
   ```

5. Open your browser:
   - Display system: [http://localhost:3000/display](http://localhost:3000/display)
   - Admin panel: [http://localhost:3000/admin](http://localhost:3000/admin)

## Supabase Setup

1. Create a new project in [Supabase](https://supabase.com)

2. Create the required tables in the Supabase SQL Editor:

   ```sql
   -- Advertisements Table
   CREATE TABLE advertisements (
     id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
     title TEXT NOT NULL,
     description TEXT,
     media_url TEXT,
     media_type TEXT DEFAULT 'image',
     active BOOLEAN DEFAULT true,
     created_at TIMESTAMP WITH TIME ZONE DEFAULT timezone('utc'::text, now())
   );

   -- Schedules Table
   CREATE TABLE schedules (
     id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
     advertisement_id BIGINT REFERENCES advertisements(id) ON DELETE CASCADE,
     start_time TIMESTAMP WITH TIME ZONE NOT NULL,
     end_time TIMESTAMP WITH TIME ZONE NOT NULL,
     created_at TIMESTAMP WITH TIME ZONE DEFAULT timezone('utc'::text, now())
   );
   ```

3. Set up Supabase Storage:
   - Go to Storage in your Supabase dashboard
   - Create a new bucket called `advertisements`
   - Set the bucket's privacy level to public (or adjust according to your needs)
   - Update bucket policies to allow read/write access

## Usage Guide

### Display System

1. Navigate to `/display` in your browser
2. The system will automatically fetch active advertisements and display them
3. Advertisements will rotate automatically every 10 seconds
4. The display is designed to be shown in fullscreen mode (press F11 in most browsers)

### Admin Panel

1. Navigate to `/admin` in your browser
2. Use the "Add New Advertisement" button to create new advertisements
3. Fill in the form fields:
   - Title (required)
   - Description (optional)
   - Upload media (image or video)
   - Set active status
   - Add schedules with start and end times
4. Use the table to view, edit, preview, or delete existing advertisements
5. The preview feature shows how advertisements will appear on the display system
